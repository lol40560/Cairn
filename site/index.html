Questions, answered.

Does Cairn upload my code?

No. Files leave your machine only when you join a room (shared with authorized peers), when local discovery advertises network metadata, or when you confirm a GitHub export.

Can Cairn stop an AI agent from overwriting my file?

Only if the agent follows the claim protocol. Strict edit protection enforces this for writes made through Cairn's editor. External tools that ignore the protocol cannot be constrained.

What happens if someone disappears mid-edit?

Claims have a 10-minute lease renewed by a 2-minute heartbeat. An abandoned claim expires on its own, and the project owner can release it earlier.

Why does my OS warn me about the installer?

Current installers are unsigned. Download only from GitHub Releases and verify the SHA-256 checksum before installing.
