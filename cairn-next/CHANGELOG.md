# Changelog

## 0.2.0-rc.2 — bright UI candidate

- 밝은 배경, 시스템 글꼴, 분명한 버튼 대비와 일관된 SVG 아이콘을 적용했습니다.
- 탐색 메뉴를 작업·협업·기록과 복구로 구분하고 첫 화면의 폴더 열기·팀 참가를 명확히 했습니다.
- 파일 생성 버튼을 이름으로 표시하고 체크포인트의 비교·복원 경로를 드러냈습니다.
- 연습 공간 종료, 비활성 작업 안내, 작은 창과 확대 화면, 동작/투명도 줄이기 및 고대비 표현을 다듬었습니다.
- 저장·파일 동기화·인증·복구 코어와 데이터 형식은 변경하지 않았습니다. 기존 0.2.0-rc.1과 같은 협업 프로토콜을 사용합니다.
- 네트워크 완료 확인을 검증하는 기존 테스트 한 곳에서 참가자에게 비동기 알림이 도착할 때까지 기다리도록 보정했습니다.

## 0.2.0-rc.1 — unreleased candidate

비공개 검증을 위한 로컬/LAN 프로젝트 버전입니다. 이 항목은 구현 변경을 설명하며, 서명·공증·공개 배포 또는 모든 플랫폼 시험 통과를 의미하지 않습니다. 실행 증거는 `docs/release-validation.md`와 `docs/release-readiness.md`에 별도로 기록합니다.

### Project workflows

- 단일 파일 중심 구조에서 일반 폴더·하위 디렉터리·안정적인 파일 ID를 사용하는 프로젝트 구조로 확장했습니다.
- 로컬 프로젝트와 팀 프로젝트가 동일한 파일 작업·편집·복구 명령을 사용합니다. 팀 생성자는 원래 작업 폴더의 writer 하나를 유지합니다.
- UTF-8 LF/CRLF 공동 편집과 16 MiB 이하 바이너리 전송을 구분하고, 미지원 항목은 디스크에 보존하며 이유를 표시합니다.
- 최근 프로젝트, 폴더 재지정, 파일 검색·생성·이름 변경·이동·삭제, 한국어·영어·번체 중국어 화면과 예제 흐름을 추가했습니다.

### Team and persistence

- 프로젝트 단위 WSS 전송, 초기 스냅샷·불변 blob 검증·후속 변경 따라잡기, 영속 outbox와 중복 명령 처리를 도입했습니다.
- 초대 역할·만료·폐기, 인증서 고정 검증, LAN mDNS 검색과 직접 주소 연결을 사용합니다.
- 로컬 보관·팀 보관·실제 폴더 반영·현재 연결된 참가자 확인을 별개로 표시합니다.
- 트레이 상주 및 독립 서버 제품 흐름을 제거했습니다. 앱 종료는 해당 앱이 열어 둔 팀 연결과 호스팅을 중지합니다. PC 서버는 Coming Soon 안내로 남깁니다.

### Recovery and external tools

- 외부 저장 기준을 별도로 추적하고, 기준이 최신인 텍스트는 최소 변경으로 반영하며 오래되거나 알 수 없는 저장은 충돌로 보존합니다.
- 명시적인 외부 편집 작업 알림과 갱신·완료·취소·만료, 선택적인 엄격한 claim 검사를 추가했습니다.
- 활동 필터·파일/세션 그룹·이전/이후 내용 비교, 충돌 버전 선택·텍스트 수동 해결, 체크포인트 및 삭제된 파일 복원을 추가했습니다.
- 복원은 보호용 체크포인트를 남기는 새 변경으로 처리합니다. 오래된 오프라인 편집은 복원을 자동으로 되돌리지 않고 복구 대상으로 남깁니다.
- 삭제된 항목 비우기는 해당 복구 목록만 대상으로 하며 별도 체크포인트를 삭제하지 않습니다. 세션 전체 롤백과 안전한 디스크 흔적 제거는 제공하지 않습니다.

### Export and distribution preparation

- 현재 내용의 ZIP을 새 경로에 원자적으로 게시하고 SHA-256·안전한 경로·바이너리 원본을 재검증합니다. 검증용 manifest에는 앱 DB·토큰·활동 기록을 넣지 않습니다.
- GitHub 읽기 전용 미리보기, 명시적 파일 선택, 기준 SHA·내용 해시 재검증, 새 브랜치와 PR 생성을 추가했습니다. 삭제 후보는 기본 선택하지 않습니다.
- GitHub 시험은 로컬 모의 REST 서버를 사용합니다. 이번 개발 작업에서 실제 PR을 만들거나 프로젝트를 업로드하지 않습니다.
- 설치·개인정보·복구 문서와 설치된 의존성의 원문 라이선스 고지 생성기를 추가했습니다.

### Compatibility and limits

- 구버전 `.cairn` 및 0.1.x 내부 DB를 직접 마이그레이션하지 않습니다. 일반 파일 사본을 새 폴더로 가져와야 합니다.
- 물리적 두 장치 LAN과 macOS의 실행·설치·IME 증거는 해당 환경에서 수집해야 합니다. Windows 자동 시험을 macOS 검증으로 대체하지 않습니다.
- macOS 후보는 Developer ID 서명·Apple 공증을 하지 않은 상태로 준비하며, 공개 배포 준비 완료로 표시하지 않습니다.

## 0.1.0 — historical prototype

하나의 UTF-8 파일, 지정 PC 호스트, Monaco/Yjs 편집, SQLite 영속 저장과 재접속을 검증한 초기 단계입니다. 당시 트레이 동작·CLI 설명·단일 파일 제약은 0.2.0-rc.1의 제품 사용 안내가 아닙니다. 과거 조사와 시험 자료는 원래 범위의 기록으로 보존합니다.
