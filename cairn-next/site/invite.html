Hosting this page or creating a share link?

After hosting this file over HTTPS, copy an invitation from Cairn Next, paste it below, and create a link. The invitation stays in the URL fragment, which browsers do not send in normal HTTP requests. Anyone holding the link can use it until it expires or is revoked.

Optional: set DOWNLOAD_URL in this HTML to the eventual Cairn Next download page. Current v2.0.3 downloads are for the original, incompatible app.
