# Cairn Next 0.2.0-rc.2 · 소스 공개와 출시 준비 상태

**현재 공개 범위는 소스 코드입니다. 바이너리 Release·스토어 배포·서명·공증 완료를 뜻하지 않습니다.** 기존 Cairn 앱과 나란히 `cairn-next/`에 별도 앱으로 제공하며 기존 앱의 프로토콜·내부 데이터와 연동하거나 자동 변환하지 않습니다.

0.2.0-rc.2는 탐색·첫 화면·편집기·버튼·복원 안내를 다듬은 밝은 UI 후보입니다. 저장·동기화·인증·복구 코어는 0.2.0-rc.1과 같습니다. 기존 Windows 로컬 기록에는 자동 검사 163개, 포장 앱 사용자 흐름 10개와 초기 종료 2종 통과가 보고됐고, 작은 창·125% 확대·키보드 포커스·동작/투명도 줄이기·고대비 확인이 포함됩니다. RC2 설치기는 이 기록에서 다시 설치하지 않았습니다.

아래 표와 설치 결과는 **2026-10-27 KST의 0.2.0-rc.1 역사적 검증 기록**입니다. 당시 판정은 **B — Windows 출시 후보 빌드·설치 검증 완료, 실기기·플랫폼 검증 대기**였습니다. 새 checkout에 대한 재실행 결과나 모든 환경의 지원 인증으로 해석하지 않습니다. 원시 QA 보고서·시험 프로필·설치기·포장 앱은 로컬 자료이며 이 저장소에 포함하지 않습니다.

당시 검증 범위에서 남아 있는 알려진 핵심 데이터 손실 결함은 보고되지 않았습니다. 모든 환경에서 결함이 없다는 보장은 아닙니다. 보완했던 확인 순서, 재시작 지연, 실패 후 복구, 초기 종료, 큰 작업 한도는 [RC1 검증 기록](release-validation.md)에 근거와 함께 정리했습니다.

## RC1 로컬 검증 요약

- Node/renderer TypeScript, 프로덕션 렌더러 빌드, `git diff --check`: 통과.
- 자동 코어·DB·파일·WSS·독립 프로세스 검사 **163/163 통과**, 실패·skip·TODO 0, 172.74초.
- **실제로 설치된 exe**에서 10개 UI 흐름 통과, renderer 예외/console 오류 0. 초기 창 즉시 종료·구버전 거절 후 종료도 각각 종료 코드 0.
- 네이티브 NSIS 설치 시험 7단계 통과, 약 100.06초. 사용자 기본 프로필을 시험한 것으로 표현하지 않습니다. 모두 격리된 `CAIRN_USER_DATA`와 시험 프로젝트입니다.
- 생산 의존성 감사: 알려진 취약점 보고 0. 제3자 고지 49개 버전·38개 원문, Electron 고지 2개 검증.

## 제한과 출시 전 사용자 확인

- 지원 내용: UTF-8 LF/CRLF 텍스트 1 MiB, 바이너리 16 MiB, 현재 프로젝트 256 MiB/5,000개 항목. 단일 원자 작업/동기화 목록 JSON은 20 MiB이며 넘으면 저장 전 거절합니다.
- 외부 프로그램의 미저장 버퍼는 알 수 없습니다. 큰 텍스트/BOM/다른 인코딩/혼합 줄바꿈은 바이너리로 보존합니다. case-only 디렉터리 이름 변경과 자신을 제외하는 `.gitignore`는 안전하게 거절합니다.
- 생성자 앱 종료 시 팀 연결이 끝납니다. 호스트 승계·다중 호스트·독립 서버·인터넷 호스팅은 없습니다. 현재 LAN 수신/주소 안내는 IPv4 기준입니다.
- 0.1.x 및 기존 `.cairn` DB의 자동 변환은 없습니다. 일반 파일 사본을 새 폴더로 가져오고 기존 기록은 따로 보존해야 합니다.
- 삭제 복구 목록 비우기는 모든 과거 blob·체크포인트·백업의 안전한 흔적 제거가 아닙니다. 과거 기록은 별도 디스크 공간을 사용할 수 있습니다.
- Windows 10 x64만 실제 검증했습니다. Windows ARM64/다른 Windows 버전, macOS/Keychain/DMG/Gatekeeper, 네트워크 드라이브/클라우드 동기화 폴더, 실제 전원 차단은 미검증입니다. 기본 Electron 아이콘이 남아 있습니다.
- 바이너리 정식 배포 전에 [두 기기 시험](two-device-check.md), 실제 OS IME, Mac 빌드/실행/설치/제거를 수행하세요. Windows 서명과 macOS Developer ID/공증은 별도 준비가 필요합니다. 필요하면 본인 시험 저장소에서 GitHub PR export를 직접 실행해 실서비스 권한을 확인하세요.
- 앱 자체 라이선스는 현재 `UNLICENSED`입니다. 소스 공개는 라이선스를 변경하지 않으며, 제3자 고지문이 앱 자체의 배포·사용 라이선스를 대신하지 않습니다.

당시 시험 설치는 정상 제거했고 격리된 검증 데이터는 보존 확인을 위해 로컬에 남겼습니다. 이 데이터와 실제 사용자 프로필·자격정보는 공개 소스의 일부가 아닙니다.
