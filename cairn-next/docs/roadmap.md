# 구현 순서와 기능 완료 기준

> 보존된 초기 계획입니다. 0.2.0-rc.1에서는 프로젝트·LAN·복구·내보내기 전체를 이번 출시 범위로 통합했습니다. 전용 PC 서버·headless·상시 운영·자동 시작·인터넷 호스팅은 명시적으로 보류합니다. 현재 범위와 검증 상태는 [출시 준비 상태](release-readiness.md)를 참조하세요.

0단계 조사: [화면 기능 대응표](legacy-ui-audit.md), [코어 기능 대응표](legacy-core-audit.md), [구조/데이터 흐름](architecture.md). 기존 구현은 정적 조사이며, 기존 앱의 전체 실행 검증을 했다는 의미가 아니다.

| 단계 | 구현 범위                                                                                                               | 다음 단계로 넘어가기 위한 증거                                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 독립 Windows 서버, 인증된 직접 WSS, 단일 UTF-8 텍스트 Yjs 공동 편집, SQLite outbox/영속 ACK, 재접속·재시작, 정확한 상태 | 별도 서버+클라이언트 프로세스 2개의 동시 편집, 분리 후 양쪽 변경, 클라이언트 재시작, ACK 후 서버 강제 종료 뒤 text/hash/DB/outbox 검증 |
| 2    | 파일 트리·snapshot+로그 따라잡기·온라인 구조 변경·외부 파일 어댑터·바이너리·ignore                                      | 다운로드 중 수정/rename/delete, watcher 자기 이벤트, baseline CAS, 동시 바이너리 양쪽 보존, 민감 파일 제외                             |

1단계 결과가 불안정하면 범위를 늘리지 않는다. 후속 단계 항목은 계획이며 TODO나 비활성 버튼으로 구현 완료를 대신하지 않는다. 기본 LAN 기능에 외부 계정·중앙 서비스·유료 API는 넣지 않는다.
