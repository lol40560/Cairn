# Cairn Next 0.2.0-rc.1 · 역사적 로컬 검증 기록

**당시 판정 B: Windows 출시 후보 빌드·설치 검증 완료, 실기기·macOS 검증 대기.** 검증일은 2026-10-27 KST입니다. 아래는 RC1에서 기록한 결과이며 현재 RC2 소스 공개나 새 checkout의 재실행 결과와 구분합니다. 현재 상태는 [출시 준비 상태](release-readiness.md)를 참고하세요.

본문에 적힌 JSON·로그·QA 화면 파일명은 **로컬에만 보관된 과거 증거**를 식별합니다. 해당 원본 보고서·프로필·개인 데이터·설치 산출물은 이 저장소에 포함하지 않습니다. 공개 브랜치에서 열거나 내려받을 수 있는 링크가 아닙니다.

## 환경과 검사 구분

- 실제 호스트: Windows 10 Home x64, build 19045.
- 개발 Node 24.19.0. 실제 Electron 45.0.0 / Node 24.22.0 / Chromium 156.0.8078.48 / SQLite 3.53.4를 확인했습니다.
- 원래 0.1.0의 35개 기반 검사를 재실행한 뒤 프로젝트 모듈을 추가했습니다. 최종 자동 검사 **163/163 통과**, 실패·skip·TODO 0, **172.74초**입니다.
- `node scripts/verify.cjs`에서 Node/renderer 타입 검사, 생산 빌드, 자동 검사를 통과했습니다. 이후 main의 초기 종료 경합 수정은 타입 검사와 실제 초기 종료 회귀 2종, 최종 설치본 전체 흐름으로 검증했습니다. `git diff --check`도 통과했습니다.
- 실제 앱은 Playwright Electron으로 제어했습니다. Browser 플러그인이 없어 해당 방법을 사용했습니다. 브라우저 모의 backend로 대체하지 않았으며 기본 폴더·저장 위치 대화상자만 시험 경로를 반환하도록 지정했습니다.
- 테스트는 실제 파일·SQLite·WSS·OS 암호화 경로를 사용합니다. 물리적 다른 두 기기, 물리 키보드/OS IME 수동 시험, macOS 시험은 아닙니다.

## 실제 설치 시험

설치 결과 JSON (install-results.json; 로컬 자료): 7단계, 약 **100.06초**, 모두 통과.

1. HKCU/HKLM 양쪽 registry view에서 기존 비시험 Cairn 설치가 없음을 확인했습니다.
2. **실제 0.1.0 설치 파일**을 새 시험 위치에 설치하고 구버전 앱으로 편집·영속 저장·암호화된 재연결 자료를 만들었습니다.
3. 같은 위치를 **0.2.0-rc.1로 업데이트**했습니다. 구버전 DB 직접 열기는 `LEGACY_PROJECT`로 거절하며 원본·작업 사본·암호화된 자료 해시가 유지됐습니다. 자동 마이그레이션 성공을 주장하지 않습니다.
4. 새 버전의 실제 Yjs 편집·체크포인트·로컬 OS 암호화 저장을 확인했습니다. GitHub 토큰 형태의 시험 문자열은 로컬 저장만 했고 외부 인증/업로드는 하지 않았습니다.
5. **설치된 exe**를 대상으로 10개 UI 흐름 (release-results.json; 로컬 자료)을 모두 통과했습니다. renderer 예외·console 오류 0입니다.
6. 같은 후보 설치기를 다시 실행하는 **동일 버전 재설치** 후 닫힌 프로젝트·프로필 전체 바이트가 같았고, 재실행해 마지막 프로젝트·편집·체크포인트·암호화된 설정을 복구했습니다.
7. 등록된 시험용 제거 프로그램을 `/S /currentuser`로 실행했습니다. 앱 exe와 설치 등록은 제거됐고 구·신 프로젝트와 프로필 **전체 파일 목록/크기/SHA-256이 동일**했습니다.

시험 프로필은 `CAIRN_USER_DATA`로 격리했으며 프로젝트/프로필은 설치 폴더 밖에 뒀습니다. 실제 사용자의 기본 OS 앱 데이터 삭제/보존을 시험했다고 주장하지 않습니다. 설치 과정의 숨은 상태나 실제 사용자 파일을 정리하지 않았습니다.

설치본 초기 종료 회귀 결과 (result.json; 로컬 자료): 화면 즉시 닫기와 구버전 프로젝트 거절 직후 닫기 모두 종료 코드 0, 각각 약 73/58ms. 설치본의 `--headless`, `--server`, `--daemon`, `--host`는 모두 종료 코드 2로 거절했습니다.

## 근거와 재현 명령

- 코어 검사 로그: 로컬 기록 `verify-final.log` (저장소 미포함).
- 최종 설치 결과: 위 설치 JSON과 연결된 설치본 UI/초기 종료 JSON.
- 설치본 협업 화면 (04-collaboration-ime.png; 로컬 자료), 충돌 비교 (06-conflict-review.png; 로컬 자료), 작은 창 (08-compact.png; 로컬 자료).
- `node scripts/verify.cjs` / `node scripts/runtime-check.cjs` / `node scripts/generate-notices.cjs --check`.
- `node node_modules/electron-builder/cli.js --win nsis --x64 --publish never`.
- `CAIRN_TEST_INSTALLER`와 선택적 `CAIRN_TEST_BASE_INSTALLER`를 지정한 `node tests/install.e2e.cjs`. 기존 Cairn 설치가 있으면 보존을 위해 중단합니다.

생산 의존성 감사 결과 알려진 취약점 보고 0이지만 별도의 완전한 보안 감사나 무결함 보장은 아닙니다. 제3자 고지에는 49개 버전·38개 원문을 포함했고 `LICENSE.electron.txt`와 `LICENSES.chromium.html`이 실제 Windows 폴더에 있음을 확인했습니다.

## 미검증·한계

- 물리적인 두 기기 LAN/Wi-Fi, Mac/ARM64 빌드·실행·Keychain·DMG·Gatekeeper, 실제 OS IME는 [수동 절차](two-device-check.md)와 [Mac 절차](user-guide.md#macos-빌드와-시험--미검증미서명)로 확인해야 합니다.
- 실서비스 GitHub token/저장소 권한·PR 생성은 하지 않았습니다. 별도 본인 시험 저장소에서 명시적으로 실행해야 합니다.
- Windows exe/설치기 미서명, Apple 공증 없음. 기본 Electron 아이콘 사용. 실제 전원 차단·저장장치 손상·네트워크 드라이브 원자성은 미검증입니다.
- 파일/프로젝트/기록 한도, 외부 미저장 버퍼, 기존 DB 직접 변환 없음, 삭제 목록과 과거 blob의 다른 보관 범위는 [준비 상태](release-readiness.md)와 [개인정보 문서](privacy.md)에 명시했습니다.
- 설치 시험이 끝난 프로그램과 시험 앱은 정상 종료·제거했습니다. 보존 확인용 격리 데이터는 로컬에 남겼으며 공개 저장소에 포함하지 않습니다.
