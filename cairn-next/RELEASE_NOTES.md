# Cairn Next 0.2.0-rc.4 — prerelease

This is a preview of the separate Cairn Next app. Its data and collaboration protocol are not compatible with the original Cairn app. Back up existing work and use copies of project files.

- Adds Cairn app icons on macOS and Windows, animated startup screens, and reduced-motion support.
- Adds five selectable accent colors for light and dark modes.
- Retains the project overview, guided setup, collaboration tools and hosted invitation links introduced in rc.3. Recipients copy the invitation into Cairn Next; direct opening from a browser is not yet supported.
- Collaboration requires the host app to remain open and devices to be able to reach each other, normally on the same LAN.

## Platform and security limits

- This is a prerelease. Installers are unsigned; the macOS DMG is not notarized. OS security warnings are expected.
- Builds target Apple Silicon macOS and Windows x64. Physical two-device LAN, macOS IME and live GitHub PR export remain unverified.
- The app stores recovery history locally; protect your device and keep independent backups. Invitations grant project access.
- Cairn Next is marked UNLICENSED. Third-party notices are included with the app.
